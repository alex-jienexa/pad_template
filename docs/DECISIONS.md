# Approved PAD v1.0 decisions

The following decisions are the implementation baseline:

| Area | Decision |
|---|---|
| CLI | Go |
| Distribution | CLI + GitHub Template Repository |
| Git platform | GitHub first; Git remains portable |
| Configuration | YAML |
| Requirements/tasks | Markdown + YAML front matter |
| State | YAML snapshot + Markdown handoff |
| Agent coordination | Protocols + structured task metadata |
| Git automation | Controlled, non-destructive by default |
| Template update | Three-way merge |

Any change requires a new ADR and explicit project-owner approval.
