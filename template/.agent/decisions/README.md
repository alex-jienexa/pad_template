# Architecture and product decisions

Store material decisions as append-only Architecture Decision Records (ADRs).

- File name: `ADR-NNNN-short-title.md`.
- Never rewrite history to make an old decision appear current; supersede it with a new ADR.
- Status: `proposed`, `accepted`, `rejected`, `superseded`, `deprecated`.
- Include context, considered options, decision, consequences, and links to affected requirements/tasks.
- A change to an approved PAD architectural baseline requires explicit project-owner approval.
